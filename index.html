定型文を整理して管理、入力も一瞬で

PhraseLauncher はキーボードだけで定型文を
整理して管理、超高速入力できる Windows 用定型文入力ツールです。

Download 使い方を見る

コンセプト

動作環境

Windows 11 / Windows 10

Features

⌨ キー割り当て入力

0–9 / A–Z のキーで、マウス不要の高速入力。

⌨ 移動も矢印キーで完結

移動も矢印キーで完結する、マウス不要の高速入力。

🔍 キーワード検索

定型文が増えても、すぐ見つかる。

📂 グループ管理

用途ごとに整理・並び替えも簡単。

🎯 使用中のアプリに合わせたタブを表示

グループごとに対象アプリを登録すると、そのアプリを使用中に開いたときに該当するタブが最初に表示されます。
登録されていないアプリでは前回のタブが表示されます。

✏ 空欄入力

定型文に {名前} と書いておくと、貼り付ける前にその部分だけ入力できます。
宛名や日付など、毎回変わる部分にも対応。

🔧 複数言語対応

日本語と英語に対応しています。

⌨ ホットキー起動

Ctrl 2回連続 (キーの種類と回数は設定で変更可能)もしくは Ctrl + Shift + O で即起動。
ホットキー起動のオンオフやキーの種類、連打回数の変更ができます。

📄 ファイルのインポート/エクスポート

CSV、JSONファイル形式でファイルのインポートとエクスポートができます。

🔒 登録している定型文は暗号化可能

登録している定型文は暗号化して保存できます。
また、設定画面からオンオフを切り替えることができます。

プライバシーについて

本アプリはランチャー起動のホットキー機能のため、キーボード入力イベントを検知します。
入力された文字内容の保存・送信は行いません。
個人情報の収集は行いません。
