Documentation

PhraseLauncher is a simple launcher that allows you to paste fixed phrases quickly using only your keyboard.

Quick Start

1. Download

Download the latest version from GitHub Releases.

👉 Releases Page

2. Launch

Run the exe file. The application will stay active in your system tray.

3. Language & Appearance Settings

Please change the language (Japanese / English), text size, or hotkey-related settings as needed.

4. Register Phrases

Right-click the system tray icon and open the Settings window to register your groups and phrases. ※ To insert a line break, use Shift + Enter.

5. Open the Launcher

You can display the launcher by pressing Ctrl twice in a row (the key type and number of presses can be changed in the settings) or by using Ctrl + Shift + O.

Operations

  • Press 0–9 / A–Z keys for instant input.
  • Type keywords to search through phrases.
  • Press Esc to close the launcher immediately.

Open the Tab Matching the App in Use

Register target apps for each group (tab), and when you open the launcher while one of those apps is in use, its tab is shown first. You can register multiple apps per group.

  • Register them with the Target Apps button on the edit registration screen.
  • Type an app name (e.g. notepad, EXCEL.EXE) or click Browse... to select an exe file.
  • If the app in use is not registered for any group, the tab that was open when the launcher was last closed is shown.
  • If the same app is registered in multiple groups, the tab that comes first in the group order is opened.
  • Apps are matched by executable name, so different websites in the same browser cannot be told apart.
  • This works when the launcher is opened with the hotkey. If you open it from the tray menu, the previous tab is shown.

Fill-in Blanks

Write {name} in a phrase to make a blank that you fill in just before pasting. 

Dear {Recipient},

Thank you for your request. We will handle it by {Deadline}.

When you select this phrase, a small input window appears with one field per blank. Type the values and press Enter to paste the completed text.

  • Move between fields with Tab; press Esc to cancel without pasting.
  • If the same name appears more than once, you only enter it once and it is used everywhere.
  • A blank name cannot contain braces or line breaks (max 40 characters).

Main Features

  • High-speed phrase input.
  • Group management and reordering.
  • Automatically open the tab matching the app in use.
  • Fill-in blanks with {name}.
  • Input line breaks using Shift + Enter.
  • Lightweight and fast performance.

How to Update

  • 1. Close the application.
  • 2. Download the new version.
  • 3. Overwrite the files in the existing folder.
  • 4. Launch the application.
